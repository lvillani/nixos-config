## Usage

The helper is beside this file. Resolve `<skill-dir>` as the directory containing this
`SKILL.md`, replace the placeholder with its absolute path, and run:

Use `search` when you need current web information or sources:

```sh
"<skill-dir>/web-search-and-fetch" search "query"
```

Use `fetch` when you have a URL and need its page content:

```sh
"<skill-dir>/web-search-and-fetch" fetch "https://example.com"
```
